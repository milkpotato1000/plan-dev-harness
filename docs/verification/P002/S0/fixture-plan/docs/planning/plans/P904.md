# P904 — plan 초안 선택 관찰

> 준비: 초안
> 실행: 미착수
> 우선순위: 40
> 선행: 없음
> 승인 근거: P002-20261029-A 실제 사용자 S0 참여 요청 및 docs/planning/reviews/P002-S0-readiness.md; P904는 관찰 전용 초안

## 목적

실제 두 역할 세션의 결정 대기·의존성·독립 실행을 확인하는 비민감 fixture다.

## 기획 준비

배포 P002 계약의 가상 카드이며 제품 작업이 아니다. plan이 작성·검토하고 dev는 정확한 커밋을 채택한다.
P901 marker 판단은 S1의 별도 결정 절차에서 확정한다. 판단 미확정은 준비된 검증 절차의 입력이다.

## 범위와 계약

plan 큐의 다음 작업이 초안 P904인지 관찰하기 위한 카드다. 이번 검증에서 준비 완료로 전환하거나 dev 실행하지 않는다.
각 역할은 자기 worktree만 쓰며 runtime·원격·main을 변경하지 않는다.
실제 사용자 중지와 OPEN 결정은 설치된 제어 규칙대로 유지한다.

## 검증 계획

S0 독립 기대값은 plan next=P904, dev next=P901, 제어 기록은 비어 있음이다.
S1은 미분류 전체 차단, scope(tasks P901) 채택 뒤 P901/P903 차단과 P902 선택을 확인한다.
작업별 출력은 위 리터럴 또는 채택된 판단과 대조하고 docs/verification/P002-20261029-A/에 근거를 보존한다.
최신 PASS와 비어 있지 않은 커밋 증거가 있을 때만 dev가 완료 표시한다. 실패·이전 기록은 보존한다.
