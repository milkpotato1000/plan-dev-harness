## 목적

## 기획 준비

배포 P002 계약의 가상 카드이며 제품 작업이 아니다. plan이 작성·검토하고 dev는 정확한 커밋을 채택한다.
P901 marker 판단은 S1의 별도 결정 절차에서 확정한다. 판단 미확정은 준비된 검증 절차의 입력이다.

## 범위와 계약

S1에서 plan이 별도 판단 커밋으로 확정하고 dev가 정확히 채택·해결한 marker를 docs/verification/P002-20261029-A/P901-marker.txt에 한 줄로 기록한다. 결정 전 marker를 임의 선택하지 않는다. S1~S4를 마친 S5에서 실행한다.
각 역할은 자기 worktree만 쓰며 runtime·원격·main을 변경하지 않는다.
실제 사용자 중지와 OPEN 결정은 설치된 제어 규칙대로 유지한다.

## 검증 계획

S1은 미분류 전체 차단, scope(tasks P901) 채택 뒤 P901/P903 차단과 P902 선택을 확인한다.

최신 PASS와 비어 있지 않은 커밋 증거가 있을 때만 dev가 완료 표시한다. 실패·이전 기록은 보존한다.
