> 준비: 초안
> 실행: 미착수
> 우선순위: 40
> 선행: P903
> 승인 근거: 미확정 — 단계 B의 실제 사용자 기획 turn에서 검토·확정 전까지 초안. payload 근거는 부모 P009 C3 보충 계약(전달 98e88dbea1b560dee31017fb980ab78a6bd934b9).

## 목적

P903 group 요약을 CSV로도 받을 수 있게 한다. 기본 JSON 출력은 그대로 둔다.
보충 시험에서 dev가 P903을 수행하는 동안 plan이 새 사용자 turn으로 검토·확정하는 후속 인계 대상이다.

## 기획 준비

초안(단계 A). 실제 사용자 검토 turn 이전에는 READY·발송하지 않는다.
확정이 필요한 항목은 docs/planning/reviews/P904-draft-review.md의 D1~D4. 각 항목에 제안 기본값이 있다.

## 범위와 계약 (초안)

- `fixture_batch.py` CLI에 출력 형식 옵션을 추가한다(제안: `--format {json,csv}`, 기본 json). JSON 출력·exit 의미는 P903 그대로.
- CSV: `csv` 모듈 사용. 헤더 `group,records,lines,characters`, 이후 P903과 같은 group 이름순 행.
  쉼표·따옴표·개행·Unicode가 포함된 group 이름은 csv 모듈 인용 규칙으로 정확히 왕복(csv.reader로 다시 읽으면 동일)되어야 한다.
- 결과 group이 없으면 헤더만 출력한다.
- exit 의미: P903과 동일(0/2/1). CSV 모드의 record 오류 보고 방식은 D2.
- 제외: CSV 입력, 파일 출력 경로 옵션, 기본 형식 변경.

## 검증 계획 (초안)

헤더만 있는 빈 결과, 쉼표/따옴표/개행/Unicode group 왕복, 결정적 순서, 중복 group 합산 반영,
CSV 모드 exit 0/2/1, 기본(옵션 없음) JSON 출력이 P903과 바이트 동일, P901~P903 회귀 PASS.
증거는 dev 보충 디렉터리.
