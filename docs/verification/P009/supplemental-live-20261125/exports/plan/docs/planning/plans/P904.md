# P904 — fixture 그룹 요약 CSV 내보내기 옵션

> 준비: 준비 완료
> 실행: 미착수
> 우선순위: 40
> 선행: P903
> 승인 근거: 2026-11-25 fixture plan 터미널의 실제 사용자 기획 turn(“P904 CSV 내보내기를 초안의 제안 기본값으로 검토·확정해. 기본 JSON과 P903 선행·오류 종료 코드는 유지하고, READY 정확 커밋을 기존 dev에 전달한 뒤 복귀해.”)과 부모 P009 C3 보충 계약(전달 98e88dbea1b560dee31017fb980ab78a6bd934b9)의 P904 payload.

## 목적

P903 group 요약을 CSV로도 받을 수 있게 한다. 기본 JSON 출력은 그대로 둔다.
보충 시험에서 dev가 P903을 수행하는 동안 plan이 새 사용자 turn으로 검토·확정하는 후속 인계 대상이다.

## 기획 준비

단계 A 초안을 실제 사용자 turn에서 제안 기본값(D1~D4)으로 확정했다. 검토: docs/planning/reviews/P904-review.md.
착수 조건: dev가 P903 완료 또는 실제 안전 checkpoint 커밋 후 이 카드의 정확 SHA를 채택. P903을 중단·재시작하지 않는다.

## 범위와 계약

- `fixture_batch.py` CLI에 `--format {json,csv}` 옵션을 추가한다. 기본은 `json`이며 옵션이 없거나 `json`이면 출력·exit가 P903과 바이트 동일하다. (D1)
- CSV: `csv` 모듈 사용. 헤더 `group,records,lines,characters`, 이후 P903과 같은 group 이름순 행.
  쉼표·따옴표·개행·Unicode가 포함된 group 이름은 csv 모듈 인용 규칙으로 정확히 왕복(csv.reader로 다시 읽으면 동일)되어야 한다.
- 결과 group이 없으면 헤더만 출력한다.
- 숫자 열은 정수 그대로 쓴다. (D4)
- 줄 끝은 csv 모듈 기본 `\r\n`을 유지한다(stdout은 `newline=""` 의미로 이중 개행 없이). (D3)
- CSV 모드 record 오류: stdout CSV에는 group 행만 쓰고, 오류는 줄 번호순으로 stderr에 `line <k>: <code>` 한 줄씩 쓴다. (D2)
- exit 의미는 P903과 동일하다: 성공 0, record 오류 1건 이상 2(CSV는 그대로 출력), 파일 I/O·UTF-8 디코딩 오류 1(stdout 없음), argparse 사용법 오류(잘못된 `--format` 값 포함) 기본 2.
- 제외: CSV 입력, 파일 출력 경로 옵션, 기본 형식 변경.

## 검증 계획

헤더만 있는 빈 결과, 쉼표/따옴표/개행/Unicode group 왕복, 결정적 순서, 중복 group 합산 반영,
CSV 모드 exit 0/2/1과 stderr 오류 줄 형식, `\r\n` 줄 끝, 기본(옵션 없음)·`--format json` 출력이 P903과 바이트 동일, P901~P903 회귀 PASS.
독립 기대값 예: group `a,"b"`·records 1·lines 1·characters 2 → 행 `"a,""b""",1,1,2`. 빈 결과 → `group,records,lines,characters\r\n`만.
증거는 dev 보충 디렉터리.
