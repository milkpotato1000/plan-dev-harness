## 범위와 계약

- 파일: 저장소 루트 `fixture_format.py`, 테스트 `test_fixture_format.py`(표준 라이브러리 unittest, 외부 의존성 없음).
- `format_lines(lines)`:
  - 입력: 문자열의 iterable(list 등).
  - 각 값의 앞뒤 공백(`str.strip()`)을 제거한다.
  - 제거 후 빈 문자열인 값(빈 줄·공백만 있는 줄)은 버린다.
  - 남은 값을 `"\n"`으로 연결하고 끝에 개행 하나를 붙인다.
  - 남은 값이 없으면(빈 입력 포함) `""`을 반환한다.
  - 내부 공백(값 중간)은 보존한다. 입력 순서를 유지한다. 입력을 변경하지 않는다.
- 제외: CLI, 파일 I/O, 비문자열 입력 강제 변환, P902 summarize_lines.

## 검증 계획

독립 기대값(예):
- `format_lines([])` → `""`
- `format_lines(["", "   ", "\t\n"])` → `""`
- `format_lines(["  a  ", "", "b"])` → `"a\nb\n"`
- `format_lines(["x"])` → `"x\n"`
- `format_lines(["a  b"])` → `"a  b\n"`(내부 공백 보존)
- 값 안의 앞뒤 `\r\n`/탭 제거, 순서 유지, 입력 리스트 불변, 제너레이터 입력 허용.
실행: `python3 -m unittest -v test_fixture_format` (dev worktree). 증거: dev 소유 `docs/verification/P009-live/`에 실제 시작/종료 시각, 채택 SHA, 커밋된 테스트 출력 기록.
실패 시 실패 출력을 보존하고 수정→재검증한다. 인위적 장시간 sleep 금지.
