P901 format_lines의 정규화 규칙을 재사용해 여러 줄 입력의 정규화된 줄 수와 문자 수를 요약한다.

## 범위와 계약

- 파일: `fixture_format.py`에 `summarize_lines(lines)` 추가, 테스트는 `test_fixture_format.py`에 추가.
- 정규화: P901 format_lines와 동일(각 값 `str.strip()`, 빈 값 제거, 순서 유지).
- 반환: `(line_count, char_count)` 튜플.
  - line_count: 정규화 후 남은 줄 수.
  - char_count: 남은 줄들의 문자 수 합. 구분자(`\n`)와 후행 개행은 제외. 내부 공백은 포함.
- 빈 입력/모두 공백 → `(0, 0)`. 입력을 변경하지 않고 임의 iterable(제너레이터 포함)을 허용한다.
- 일관성: 비어 있지 않은 결과에서 `char_count == len(format_lines(lines)) - line_count`.
- P901 format_lines의 동작·시그니처는 변경하지 않는다. 제외: CLI, 파일 I/O, 비문자열 변환.

## 검증 계획

독립 기대값:
- `summarize_lines([])` → `(0, 0)`; `summarize_lines(["", "  ", "\t"])` → `(0, 0)`
- `summarize_lines(["  ab  ", "", "c"])` → `(2, 3)`
- `summarize_lines(["a  b"])` → `(1, 4)`(내부 공백 포함)
- `summarize_lines(["é", "x\r\n"])` → `(2, 2)`(문자 단위, 개행 제외)
- 제너레이터 입력, 입력 불변, format_lines와의 일관성 관계.
실행: `python3 -m unittest -v test_fixture_format` — P901 기존 테스트 전부 회귀 PASS 포함.
증거: dev 소유 `docs/verification/P009-live/`에 채택 SHA, 실제 시작/종료 시각, 커밋된 테스트 출력.
