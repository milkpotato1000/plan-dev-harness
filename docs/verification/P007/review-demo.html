역할과 기록

Dev는 정확히 채택한 P를 구현·검증하고 결과/실패와 artifact 버전·hash, 질문 범위, 공통 request key를 커밋합니다. Plan은 원장과 기존 답변을 확인하고 read-only 파일·뷰를 먼저 검토합니다. 기존 합의 내 판단은 확정하고 실제 사람 판단만 한 번 질문합니다.

관찰 범위

이 페이지는 검토 규약과 검증 분류를 설명하는 정적 artifact입니다. 표의 답변·질문 수는 가상 fixture이며 실제 사용자 승인 기록이 아닙니다. 파일 내용 읽기, 링크 제공, 실제 시각 확인과 사람 확인은 구별합니다. Plan의 실제 viewer 관찰 여부는 plan 원장에 별도로 기록합니다.

새 runtime schema·자동 질문 차단기·sender·monitor는 추가하지 않았습니다. 기존 transport event는 의미적 질문 중복까지 자동 해결하지 않습니다. 실제 역방향 전달은 해당 프로젝트의 인간 위임이 필요합니다.

기존 P007 계약과 references/user-review.md, assets/docs/process/user-review-template.md, docs/verification/P007/policy-review.md를 함께 검토합니다. 범위 내 검토는 plan에서 기록하며 이 artifact 자체에 새 사람 승인 기준은 없습니다. 선택적 검토가 독립 승인 작업을 막지 않도록 합니다.
