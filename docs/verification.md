Command: `python3 -m unittest discover -s tests -v`. For 3.13, PATH also pointed
`python3` to that interpreter so Git hooks and child processes used the same runtime.
The production scripts use Python standard library only. The external skill metadata
validator uses PyYAML; that is a development validation dependency, not an install
or runtime requirement.

The tests create real disposable Git repositories. Coverage includes exact SHA
adoption, branch ownership, staged and pushed snapshots, latest PASS evidence,
append-only execution failures, immutable request records, protected plan decisions,
queue visibility without merging dev into plan, collision/symlink/hook refusal,
unchanged-file upgrades, both agent skill destinations, self-contained copied
scripts, new nested workspaces and legacy worktree migration.

Failures found and corrected before release:
- Generic packaging initially omitted the new intake module; bundled it and its tests.
- Python 3.9 does not parse trailing-Z ISO timestamps directly; normalized UTC offsets.
- macOS /var and /tmp aliases were mistaken for user-created symlinks; accepted only
  their exact system targets while retaining arbitrary symlink refusal.
- A test fixture accidentally committed generated bytecode. Added ignore rules in
  that fixture; full suites now pass in both runtimes.

The passing logs are final runs. No model-driven Codex/Claude session was executed
to certify agent behavior. Linux, WSL and native Windows were not tested. Local Git
hooks are bypassable and are not a security boundary. See [compatibility](compatibility.md).
