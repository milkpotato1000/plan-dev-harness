# plan-dev-harness v0.2.3

정식 누적 배포일: **2026-11-24 (Asia/Seoul)**. MIT License.
GitHub의 실제 발행 시각은 별도 메타데이터에 기록됩니다.

v0.1.0 이후 개발한 결정 영향 분류·명시적 중지/재개, 새 세션의 역할 복원,
비동기 plan→dev 인계와 plan 단일 사용자 검토 창구를 함께 배포합니다.
0.2.0·0.2.1·0.2.2는 이번에 포함된 개발 이정표이며 별도의 정식 릴리스가 있었다는 뜻은 아닙니다.

- 관련 작업과 의존 작업만 결정 대기로 차단하고, 범위 미분류 OPEN은 보수적으로 처리합니다.
- 결정 해결과 사용자 중지를 분리하고 실제 재개 요청·checkpoint 이력을 보존합니다.
- plan은 정확 계획을 전달하고 SENT 기록 후 종료합니다. dev는 안전한 경계에서 정확 SHA를 채택합니다.
- 결과 검토와 필요한 사용자 질문을 plan으로 모으고, 같은 대상·버전·범위의 실제 답변을 재사용합니다.
- preview와 기존 파일 보존을 유지하며 회사 Claude Code용 버전 고정 설치 안내를 제공합니다.

## Claude Code 설치

[전체 설치 안내](https://github.com/milkpotato1000/plan-dev-harness/blob/v0.2.3/docs/claude-code-install.md).
새 목적지에 clone한 뒤 미리보기의 설치 경로를 확인하고 적용하세요.

```sh
git clone --branch v0.2.3 --single-branch https://github.com/milkpotato1000/plan-dev-harness.git plan-dev-harness-v0.2.3
cd plan-dev-harness-v0.2.3
python3 scripts/install_skill.py --agent claude
python3 scripts/install_skill.py --agent claude --apply
cat "$HOME/.claude/skills/plan-dev-harness/VERSION"
```

새 Claude Code 세션에서 `/plan-dev-harness`를 사용합니다.
배포 형식은 **SKILL.md + Python CLI**이며 marketplace 플러그인이 아닙니다.
공개 소스 다운로드와 설치에 별도 GitHub 토큰·MCP 연결은 필요하지 않습니다.
설치기는 동일 사본은 KEEP, 다른 기존 사본은 보존하고 거절합니다. 스킬 설치기의 `--upgrade` 옵션은 없습니다.

## 검증과 경계

Python 3.9 이상·Git 2.31 이상·POSIX shell 기준입니다. macOS의 전체 회귀와 격리된
Claude 스킬 설치 preview/apply/KEEP/충돌 보존·독립 CLI 실행을 확인합니다.
[후보 검증 기록](https://github.com/milkpotato1000/plan-dev-harness/blob/v0.2.3/docs/verification/P008/README.md)과
[dev의 후행 발행 검증](https://github.com/milkpotato1000/plan-dev-harness/tree/dev/docs/verification/P008)을 구분합니다.
main/tag는 검증한 후보에 고정하며 발행 후 원격·공개 태그 설치 증거는 dev에 별도 커밋합니다.

실제 회사 Claude Code 로그인·조직 정책·모델 대화, Linux/WSL 실행과 native Windows는
이번에 검증하지 않았습니다. 스킬 설치는 기존 프로젝트 업그레이드·중지 해제·채팅 간 자동
발송을 하지 않습니다. 실제 host 도구와 인간 위임이 없으면 파일 인계를 사용합니다.
P002의 역사적 0.2.0 시험과 별도 continuation 한계는 원래 증거에 그대로 보존합니다.
