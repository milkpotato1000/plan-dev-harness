## 목적

Codex가 승인된 작업을 기존 Claude plan/dev 세션에 전달하고, 사용자가 매번 터미널에
계속 문장을 입력하지 않아도 수신 세션이 기존 역할로 진행하게 한다.

## 기획 준비

[상세 계약](../P011-official-claude-relay.md), 준비 검토와 dev 인계 문서를 따른다.
P010 소스 0.2.5의 등록/인계 체계를 기술 기준으로 사용한다. P009/P010 전체 완료를
선행으로 요구하지 않으며 기존 미완료 조건과 실패를 그대로 유지한다.

## 범위와 계약

공식 `claude -p`와 native ListAgents/SendMessage를 조합한 제한된 전달 adapter를
소스/설치형 0.2.6에 추가한다. 공식 기능의 조합이지 별도 공식 Codex↔Claude 제품이라고
표현하지 않는다. 중계 세션은 전송만 하며 기존 plan/dev writer를 대체하지 않는다.
권한·inbound 제한·명시 중지·OPEN·현재 작업·정확 SHA 채택을 보존한다.
전송 수신 경로가 없는 환경은 구체적 pending으로 보고하고 UI 차단을 우회하지 않는다.

## 검증 계획

상세 W1~W7의 기능 확인, identity/발송 내용/중복·전송 불명 검증, 비용·시간 제한,
idle/busy/held/refused/중지/재연결 경계, 실제 기존 Claude 수신 및 설치·업그레이드·회귀를 수행한다.
모델의 성공 문장이나 CLI exit 0만으로 메시지 전달·수신·업무 완료를 주장하지 않는다.
