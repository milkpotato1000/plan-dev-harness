# P009 — plan 실행 승인과 독립 dev worker의 비동기 실행

> 준비: 준비 완료
> 실행: 미착수
> 우선순위: 70
> 선행: P008
> 승인 근거: 2026-11-24 실제 사용자 독립 plan/dev 병렬 실행 구성 요청 및 docs/planning/reviews/P009-readiness.md

## 목적

사용자는 plan에서 결정하고 다음 기획을 계속한다. 별도 dev 세션은 승인된 P를 수신·적용하고
순차 구현한다. 사용자에게 dev 채택 문장 입력을 다시 요구하거나 plan이 구현을 대신하지 않는다.

## 기획 준비

[상세 계약](../P009-independent-dev-worker.md)과 준비 검토·dev 인계를 따른다.
P008 0.2.3 배포를 먼저 완료하고 안전한 경계에서 P009를 채택한다.

## 범위와 계약

설치형 0.2.4의 역할/실행 승인/내부 적용 용어, 독립 worker 확인·전달 절차, Claude Code 두
터미널 adapter, 진단과 격리 검증을 구현한다. 기존 Codex 두 채팅 경로를 유지한다.
이번 프로젝트의 plan-owned 운영 지침도 수정하고 dev는 정확 채택한다.
0.2.3 main/tag/release, 기존 P/중지/설정/다른 프로젝트를 보존한다.

## 검증 계획

상세 W1~W7의 전달 성공/실패/보류, 중복/잘못된 수신자/동일 세션/바쁜 dev/결정/중지,
독립 세션 중첩 실행, 설치형/진단/전체 회귀를 검증한다. Claude 실제 두 터미널 시험은
사용자가 준비된 격리 폴더에 세션을 연 후 수행하며 시뮬레이션으로 대체 통과시키지 않는다.
