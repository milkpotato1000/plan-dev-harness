## 목적

기존 설치 프로젝트에도 0.2.1의 새 세션 역할 복원·문서 전달 및 설치 기능을 적용하되,
기존 제품 작업·미채택 계획·실행 증거·명시 중지·커스텀 보호 규칙을 유지한다.

## 기획 준비

[P005 보존 업그레이드 계약](../P005-existing-installations.md)과 준비 검토를 따른다.
배포 저장소의 설치 runtime과 발견한 세 기존 제품 설치가 대상이다. 실제 로컬 경로와
프로젝트별 비공개 상태는 Git 밖 로컬 inventory에 보관한다.

## 범위와 계약

관리 설치는 동일 옵션 preview 후 업그레이드, legacy 설치는 커스텀 runtime/지침을
검토 통합한다. dev는 보호 파일 변경안을 격리된 proposal로 준비하고 plan이 검토·커밋한
정확 대상별 SHA만 채택한다. 무조건 최신 plan을 채택하지 않는다. 기존 상품 큐 실행,
중지 해제, 새 외부 메시지 위임, 외부 서비스 수정, main/릴리스/태그 변경은 제외한다.

## 검증 계획

전후 상태 fingerprint, legacy custom guard/큐 회귀, 0.2.1 설치 파일/역할 지침 검사,
각 dev의 worktree/index/HEAD guard 및 큐 비교, 기존 원격 plan/dev ref 일치 검증.
동작 미검증을 버전 표기만 바꿔 완료로 처리하지 않는다.
