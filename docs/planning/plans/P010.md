# P010 — 세션 자동 등록·재연결과 설치형 연동

> 준비: 준비 완료

> 선행: P008
> 승인 근거: 2026-11-26 실제 사용자 P010 기획·dev 전달·설치형 반영 요청 및 docs/planning/reviews/P010-readiness.md

## 목적

역할별 프로젝트 구성을 한 번 설정한 뒤 Claude Code 또는 Codex를 실행하면 실제 세션이
자동 등록되고 같은 프로젝트의 상대 역할을 발견한다. 재접속 때 사람이 세션 ID를 복사하지
않아도 된다. Plan은 승인한 P를 독립 dev에 전달한 뒤 다음 기획을 계속한다.

## 기획 준비

[상세 계약](../P010-session-registration-reconnect.md), 준비 검토와 dev 인계를 따른다.
P009의 검증된 소스 0.2.4를 기술 기준으로 사용하되 P009 전체 완료를 선행으로 요구하지 않는다.
P009 C3 미충족, 기존 작업·실패·중지·OPEN 결정을 그대로 보존한다.

## 범위와 계약

소스/설치형 0.2.5에 프로젝트별 역할 설정, 로컬 세션 등록부, 공식 lifecycle hook,
상대 발견·재연결, host별 전달 연동과 읽기 전용 진단을 추가한다.
등록은 실행 승인·전송 성공·작업 재개가 아니다. 기존 writer를 대체하거나 plan이 구현하지 않는다.
공개 main/tag/release, 개인 전역 설치, 다른 프로젝트 일괄 업데이트는 범위 밖이다.

## 검증 계획

상세 W1~W7에 따라 시작 순서, 재접속, 동시 등록/충돌, 오래된 종료 이벤트, 잘못된 프로젝트,
권한·기능 부재, 중지·결정·busy 보존, 실제 host 시작 및 설치/업그레이드·전체 회귀를 검증한다.
모의 hook 입력은 실제 두 세션의 자동 연결·전달 시험을 대신하지 않는다.
